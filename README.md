# לוח אירועים משותף לכיתה

אתר סטטי בעברית ללוח אירועים של הכיתה. האתר יכול לפעול במצב דמו או להתחבר ל-Firebase.

## הרצה מקומית במצב דמו
מודולים של JavaScript דורשים שרת מקומי. אין לעשות לחיצה כפולה על קובץ ה-HTML.

ב-PowerShell בתיקיית הפרויקט:

```powershell
py -m http.server 8000
```

ואז לפתוח: `http://localhost:8000`

הכיתוב «מצב דמו - הנתונים נשמרים רק אצלך» אומר שהנתונים נשמרים רק בדפדפן המקומי. ה-JSON נקרא דרך בדיקה בטוחה: אם נתוני localStorage פגומים, האפליקציה מאפס את הדמו במקום לקרוס.

## 1. יצירת Firebase
1. פתחו https://console.firebase.google.com והיכנסו לחשבון Google.
2. צרו פרויקט חינמי חדש.
3. ב-Build → Authentication לחצו Get started והפעילו Sign-in method מסוג **Anonymous**.
4. ב-Build → Firestore Database בחרו Create database ואז Production mode.

## 2. חיבור האתר
פתחו `js/firebase-config.js` והחליפו את הערכים שמתחילים ב-`YOUR_` בערכי Web app אמיתיים של Firebase.

לאחר החלפה תקינה האתר יעבור אוטומטית ממצב דמו ל-Firebase. כל שימוש ב-Firestore עדיין מחייב Publishing של Rules.

## 3. פרסום Rules
ב-Firebase פתחו Firestore Database → Rules והעתיקו את כל התוכן מקובץ `firestore.rules`, ואז לחצו Publish.

שינויים חשובים:
- מספר הנוכחות אינו נשמר במסמך האירוע. הוא מחושב מתוך מסמכי התת-אוסף `attendees`.
- לכן אין כלל שרשרת שמאפשר למשתמשים לשנות `attendeeCount` ישירות.
- כל פריט אישי ב-`personalLines` חייב להיות מחרוזת של עד 120 תווים.
- שם פרטי בהירשמות לפריט חייב להיות מחרוזת באורך 1 עד 30 תווים.
- כללי המארחת, הנוכחות וההרשמות נשארו עם אימות בסיסי ומוגבלים למשתמש המחובר אנונימית.

## 4. Firebase Authorized domain
ב-Authentication → Settings → Authorized domains הוסיפו את דומיין GitHub Pages, למשל `YOUR-USERNAME.github.io`.

## 5. פרסום ב-GitHub Pages
1. צרו מאגר GitHub חדש והעלו את התיקייה לשורש המאגר.
2. פתחו Settings → Pages.
3. בחרו Branch בשם `main` וב-Folder בחרו `/ (root)`.
4. שמרו והמתינו לדיפלוי.

קישור האתר בדרך כלל יהיה:

```text
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
```

## עריכה ושחזור
עריכת אירוע ומחיקתו אפשרית רק מהדפדפן והמכשיר שיצרו אותם. אין קוד שחזור ואין מעבר בין מכשירים. אם מנקים נתוני גלישה או מחליפים מכשיר, אין דרך לשחזר את הרשאות העריכה בממשק הנוכחי.

## פריטי ארגון
- יש להזין שם פריט לכמות בין 1 ל-99.
- אפשר לבחור אם מספר בנות יכול לקחת את אותו פריט.
- כל בנות יכולות לבטל את ההרשמה שלהן.
- שם הפרטי נשמר ב-localStorage ומוצע שוב באופן נוח בהירשמות הבאות במצב דמו.

## שיתוף והוספת יומן
בדף האירוע יש כפתור העתקת קישור, כפתור WhatsApp וחיסכון לקובץ `.ics` להוספת האירוע ליומן.

## תמונות
תמונות jpg/png/webp נדחסות בדפדפן לרוחב מקסימלי של 1000px, לקובץ JPEG באיכות 0.7 ועד גודל דחוס של כ-700KB.

## Firebase ומצב דמו
במצב דמו כל ההרשמות והנתונים נשמרים רק בדפדפן. במצב Firebase הקוד משתמש ב-Anonymous Authentication וב-Firestore. חשוב לבדוק את האתר מול פרויקט Firebase אמיתי לפני פרסום בכיתה.
